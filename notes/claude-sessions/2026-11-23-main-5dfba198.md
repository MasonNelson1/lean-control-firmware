**Usage** (run from `wheelchair-firmware/`; needs the tap running):
```bash
python.exe tools/chair_config.py list                 # id, group, name, value, default, limits, units, unsaved flag
python.exe tools/chair_config.py list --json
python.exe tools/chair_config.py get 92 "deadzone"    # id or case-insensitive substring
python.exe tools/chair_config.py get "normal / integral"   # "group / name" when a name repeats
python.exe tools/chair_config.py set "full lean left" 1.8 "deadzone" 0.3   # applies to RAM, like dashboard Apply
python.exe tools/chair_config.py save                 # persists, like dashboard Save
python.exe tools/chair_config.py revert               # drops unsaved RAM changes
```
- **Committing a change:** `set` takes effect immediately, and `save` keeps it after power-off. There's no separate commit step. Settings marked "restart" only take effect at the next power-on.
- **Exit codes:** 0 ok, 2 bridge or link error, 3 refused because the chair isn't in DISARM, 4 the firmware rejected the value or combination.
- **`set` before sending anything:** it checks every value against the firmware's min/max and refuses ambiguous names. On success it prints `old -> new` using the value the chair sent back.
