**What the page shows:**

Old code mostly coasted or kept going; the branch brakes and then holds. There's also a chart of a stop's phases, the stop-time bars against the 0.5 s spec, and a grid of when the chair is held vs free.
2. **LEAN never coasted, before or after.** Sitting up has always made the motors slow the chair. The branch only adds brake current for the last bit, then holds. Now the only places it coasts are Assist and DISARM with a rider seated, after the stop. Pressing DISARM at speed now brakes at about 0.38 g. The basketball callout says this plainly.
3. **Steering:** turn rate is 160°/s on every speed-knob setting (it used to scale with the knob, 80–318°/s). It's capped at speed by a sideways-acceleration limit, and steering no longer drops out while speeding up. Reverse is half speed, and a back lean while rolling forward only brakes to a stop. The reverse turn flip now fades instead of jumping.
4. **Calibration and settings:** step-by-step diagrams for neutral, range and tare, plus what survives a power-off. Sensor zeros and lean ranges are saved; neutral is not. Also the new lean math, the seat-check hysteresis, and chips for every setting removed, added or tightened, plus the dashboard's new health badge.
5. **Assist and testing:** Assist is now one push, one fading boost, with no runaway. There's a 14-step wheels-off checklist, mostly the VESC Tool settings the code relies on, and 8 open questions for the team.

**Where the code contradicts the agent's summary:**
- **"Dashboard live edits" isn't in the diff.** Settings edits are still DISARM-only, and are now also refused while the chair is braking or the wheels are turning. What the dashboard actually gained is a health badge and a lean-range readout.
- **"Faults disarm" is only half the story.**
  - In Assist, a sensor or motor-controller fault just drops the boost: no braking, no hold.
  - A broken (open) sensor wire isn't detected at all. Only shorts trip the fault. The new math does stop a broken wire from causing motion.
- **The watchdog doesn't brake during a freeze.** It restarts the Teensy after 0.5 s. Until then, the VESCs' own timeout settings decide what happens, and the firmware can't set those. With VESC defaults the chair keeps its last speed command for up to about 0.5 s.
- **"Brakes instead of coasting" needs two caveats.**
  - Normal LEAN driving never coasted in the old code either.
  - The header comment in `StopController.h` still says a stop ends with the chair rolling freely. In most cases the branch now holds it instead.
- **The summary leaves out that stops miss the 0.5 s spec on knobs 2–4.** The agent's own code comment admits it (0.56, 0.89 and 1.22 s).
- Minor: a comment in `Registry.h` points to `Persistence::saveSelected`, which doesn't exist. The real function is `saveCalibration`.
