3. **Step response:** 0 → 60 RPM step and 60 → 0, twice. Record the time to 90%, the overshoot and the settling.
4. **Braking:** spin to 90 RPM, then 15 A brake current. Record the time to < 3 RPM per side.

**How the field stays out of EEPROM:** it is field 110, OFF/RUN, and I added a RAM-only flag for it to the config framework.
- Every save leaves it out: EEPROM, profiles and the unsaved-changes flag.
- Loading ignores it if it ever shows up in stored data, so it is OFF at power-on.
- The dashboard's profile save sends every field, so the firmware drops this one from the upload before writing.
- Revert, restore-defaults and switching profiles all reset it to OFF.
- A change to only this field no longer starts the 2 s auto-save.
- It costs 0 profile bytes. A dashboard upload that includes it still fits; a test checks that.
