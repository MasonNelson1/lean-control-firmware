Lean math: current firmware vs using all four sensors

Same real sweeps (E6, Mason, 23:06–23:07, config F5 B6 L5 R5), run through four versions of the math. Output 0 = no command, 1 = full command in that direction.

What it shows
  • Tonight's settings (A): lean turning is effectively off (side gains 0.01 give at most 0.007). Forward hits full command one-third of the way into the lean, so the rest of the lean does nothing (on/off feel). Back never gets past 75% of full reverse.
  • Default gains (B): turning works, but back tops out at 56% and left/right at ~63%.
  • All four sensors (C, D): every direction runs smoothly from 0 to full across the whole lean, with no early saturation and no cap.
  • Resolution is about the same for every sensible version (forward ≈10, back ≈6, left/right ≈27 steps). The limit is how still a person can sit, not the electronics or the math. The math decides how well that resolution is used.
