# Claude Code sessions

Every Claude Code session run on LEAN from 11/21 to 11/25, exported so that anyone's AI assistant can see how decisions were reached, not just the results. Times are UTC.

- **What's in them:** what was typed (Charles, or the brief when one Claude thread delegated to another), Claude's replies, and a one-line note for each tool call.
- **Left out:** tool output (file dumps, logs), Claude's internal reasoning and system messages.
- **Privacy:** personal details were removed: the rider's and sponsor's names, non-team people, places, other projects and local paths. Paths show up as `<repo>`, `<worktree>` and `~`.
- **Start here:** `2026-11-22-main-aeb9fa31.md` is the main thread. It covers the live meeting on 11/21–22, the court ride and the follow-up. The council threads are independent firmware reviews (Opus 5.5 and Fable 5.2) and their fix rounds.
- **Snapshots:** the 11/25 sessions were exported while they were still running.
